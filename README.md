# 株式会社ALCS コーポレートサイト（トップページ）

`index.html` をダブルクリックするとブラウザで開けます。

## 構成
- index.html … トップページ
- css/style.css … デザイン
- js/main.js … メニュー開閉・スクロールアニメーション・数字カウントアップ
- images/ … 写真置き場（下記ファイル名で入れると自動で表示されます）

## 要確認・差し替えが必要な箇所
- **代表メッセージ**：現サイトに掲載がないため、ALCSの理念をもとに作成した仮の文章です。代表の確認が必要です。
- **ニュース**：3・4件目は【ダミー】表記の仮記事です。
- **事業内容の説明文・サービス項目**：現サイトの情報と実績事例から再構成したものです。
- **メールアドレス**：現サイト採用ページ記載の info@alcs.co.jp を使用しています。
