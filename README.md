# 株式会社ALCS コーポレートサイト（トップページ）

`index.html` をダブルクリックするとブラウザで開けます。

## 構成
- index.html … トップページ（ファーストビュー → ニュース → ALCSについて → 事業内容 → …）
- business/ … 事業内容の下層ページ
  - hr-outsourcing.html … 01 人材アウトソーシング
  - growth-support.html … 02 採用／営業／DX伴走支援
  - telecom-event.html … 03 通信イベント事業
  - construction.html … 04 施工管理事業
- css/style.css … デザイン
- js/main.js … メニュー開閉・スクロールアニメーション・数字カウントアップ
- images/ … 写真置き場（下記ファイル名で入れると自動で表示されます）

## 要確認・差し替えが必要な箇所
- **代表メッセージ**：現サイトに掲載がないため、ALCSの理念をもとに作成した仮の文章です。代表の確認が必要です。
- **ニュース**：【ダミー】表記のものは仮記事です。
- **事業内容の説明文・サービス項目**：現サイトの情報と実績事例から再構成したものです。
- **下層ページの「ご支援の流れ」**：一般的な進め方として作成した仮の内容です。実際の進め方に合わせて修正してください。
- **メールアドレス**：現サイト採用ページ記載の info@alcs.co.jp を使用しています。
- VIEW ALL / READ MORE / プライバシーポリシーのリンクは下層ページ未作成のため `#` のままです。
